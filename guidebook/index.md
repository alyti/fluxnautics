# Mekanism: Fluxnautics

Welcome to **Mekanism: Fluxnautics**!

## Introduction
Fluxnautics is an addon mod to Mekanism, adding Sable physics engine capabilities as Mekanism machines.

## Beta Disclaimer

This mod is still being actively developed, as such many components are still using placeholder assets or don't have their UI and rendering fleshed out fully.
